# 🤖 AI Learning Roadmap Agent

An AI-powered Telegram bot that creates personalized learning roadmaps based on the user's goal and available time.

### 🚀 Features

* AI-generated learning roadmaps
* Telegram bot integration
* Weekly study plans
* Project suggestions
* Google Sheets storage
* Automated with n8n

### 🛠️ Tech Stack

* n8n
* OpenAI
* Telegram
* JavaScript
* Google Sheets

### 🔄 Workflow

```text
Telegram → AI Agent → JavaScript → Google Sheets → Telegram
```

### 💬 Example

```text
"I want to learn Python in 2 months"
```

The bot generates a structured 8-week Python learning roadmap and sends it directly to Telegram.
